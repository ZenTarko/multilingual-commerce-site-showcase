# Multilingual Commerce Site

A responsive frontend catalogue and enquiry prototype in Turkish, English and Russian.

## Overview

This web project explores multilingual product discovery and persistent browser-side cart state.

## Implemented Features

- Catalogue category filters, search, sorting and product-detail galleries.
- Cart quantity changes/removal, totals and localStorage persistence.
- Three language versions and product language switching.
- Client-side enquiry validation and formatted quote previews.

## Technologies

HTML · CSS · JavaScript · localStorage · Clipboard API

## Status and Verification

Frontend Prototype. Five cart-core tests passed; cart persistence, search and language switching were checked in a browser. There is no implemented payment processor or order-fulfilment backend.
